# Line Editor Help

## insert

Inserts a new line at the specified position.

Usage:
insert <line_number>

Example:
insert 2

## delete

Deletes the specified line.

Usage:
delete <line_number>

Example:
delete 2

## display

Displays all lines in the document.

Usage:
display

Example:
display

## save

Saves the document to a text file.

Usage:
save

## load

Loads the document from a text file.

Usage:
load

## help

Displays the available commands.

Usage:
help

## exit

Exits the line editor.

Usage:
exit
